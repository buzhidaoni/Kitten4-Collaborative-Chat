# Kitten4 协作聊天

在 [Kitten4](https://kitten4.codemao.cn/) 的**多人协作**里开一个私下聊天窗口。消息不写进作品、不在画布留痕，双方都装插件才看得到。

## 这是什么

编程猫 Kitten4 的多人协作只能改积木，没法说话。这个扩展在协作频道里开一条**旁路**：把聊天消息伪装成一条原生注释发出去，对方的插件在它变成积木评论之前截下来，所以画布上永远看不到东西。

- 不依赖任何第三方服务器，走的就是协作本身的 WebSocket
- 消息 1.5 秒后自动删除，服务器上不留档
- 只在编辑器首页（`https://kitten4.codemao.cn/`）生效，单人编辑时不出现

## 功能

- **液态玻璃面板**：材质跟着编辑器当前主题变色（经典黄 / 清爽蓝 / 翠石绿 / 元气橙 / 星辰紫 / 桃花红），换主题不用刷新，立刻跟上（监听样式变化，无轮询）
- **可拖动的悬浮球**：参考苹果辅助触控，拖到任意位置就停在哪儿（不吸边），位置记在本机；球在右半边时面板自动翻到左边，永不出屏
- **文字 + 图片 + @**：图片自动压到长边 600px、≤52KB；被 @ 的消息高亮并带 `@我`，如果它已经被刷到上面，输入框上方会浮出「谁 @ 了你 ↑」，点一下滚过去
- **透明图也能发**：PNG / WebP 带 alpha 的图会先探一遍透明度，透明处不会被压成黑块，透明区域直接透出底下的玻璃，不铺棋盘格、不垫白底
- **一次多张图**：最多 9 张，发送后只占**一个**气泡，排成宫格，点任意一张看大图
- **未读提醒**：面板关着收到消息，悬浮球角标显示条数；标签页标题变成 `（你有n条消息未读）…`。**面板开着但人切到别的标签 / 窗口时同样算未读**，切回来立刻还原
- **身份不清不楚时不瞎编**：昵称与协作 id 来自站点推送的在线成员信息，界面显示 `名字 #id`，时间精确到秒

## 安装

**方式一：下载 zip（最简单）**

1. 下载 [`dist/Kitten4-Collaborative-Chat-v3.8.zip`](dist/Kitten4-Collaborative-Chat-v3.8.zip)；
2. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`），打开右上角「开发者模式」；
3. **把 zip 直接拖进这个页面**（它会自动解压），或者解压后点「加载已解压的扩展程序」选解压出来的那一层；
4. 看到「Kitten4 协作聊天」就成功了。

**方式二：克隆仓库**

```bash
git clone https://github.com/<你的账号>/kitten4-collaborative-chat.git
cd kitten4-collaborative-chat
```

然后「加载已解压的扩展程序」→ 选仓库根目录（含 `manifest.json` 的那一层）。

> **图标必须在根目录**。这一层需要 `manifest.json`、`inject.js`、`content.js`、`style.css`、`icon16/32/48/128.png`、`icon.svg`。
> 只覆盖那 4 个 js/css 会报「缺少 icon，无法安装」；图标也不能放子文件夹——Edge 拖 zip 安装时解包器会把子目录压平，`icon/icon16.png` 会变成一个名字带乱码的文件，于是报 `Couldn't load icon`。

改过文件后：回扩展页点刷新，再刷新 Kitten4 网页。

> **装好/更新后不用猜要不要刷新**：扩展会在你已经开着的 Kitten4 页面底部直接弹一条网页提示「请刷新本页一次，聊天球就会出现」，带「刷新页面」按钮；新打开的标签页则自动生效、不提示。

自检：`node tools/verify-package.js <扩展目录>` 会逐个核对清单引用的文件和图标尺寸，提示「全部通过」才装得上。

## 使用

1. 打开**多人协作**作品。单人编辑不会建立协作连接，悬浮球**不会出现**（这是故意的）。
2. 进了协作房间才会出现玻璃球（默认左下角）。状态行显示 `已连接 · 作品名（房间号）`，例如 `已连接 · 测试（337320487）`——作品名实时读页面顶栏那个输入框，改名会跟着变；作品名容易重名，括号里的 `work_id` 才是唯一标识。
3. **点球展开，再点球收起**，没有 × 按钮，开合都有弹簧动画。球可以按住拖到任意位置。
4. 气泡右上角出现 ✓ = 服务器已回执。
5. 输入框左边两个玻璃小按钮：**＠** 拉出在线成员列表（键盘上下选、回车插入），**图片** 选图（Ctrl/⌘ 多选，最多 9 张）。
6. 想看大图就点图片；发出去的消息会在气泡右上角出现 ✓（服务器回执），不用看控制台。

## 原理

注入脚本以 `world: "MAIN"` 抢在页面脚本之前接管协作 WebSocket，对协作 socket 做一层包装：

- **发送**：把一条聊天消息伪装成**一条原生注释**，随正常的协作操作发出去
- **接收**：在 `operation_relay` 到达 Blockly 之前拦下它，带暗号的帧不往上抛，注释永远不会被渲染
- **清理**：发出去 1.5 秒后自动发删除包，阅后即焚

因为走的是协作通道本身，所以不需要任何额外服务器，双方都装插件就能互通。

### 帧格式（实测）

| 动作 | 帧 |
| --- | --- |
| 连接 | `wss://socketcoll.codemao.cn:8098/collaborate/?work_id=<id>&EIO=3&transport=websocket` |
| 入房 | 发 `42["join",<workId>]` ← 收 `42["join_ack",{code:1,data:{doc,revision}}]` |
| **发送** | `42["operation",{revision,op:[[cmd]],lock:[]}]` |
| 回执 | `42["operation_ack",{code:1,...,user_id}]` |
| **接收** | `42["operation_relay",{code:1,op:[[cmd]],...}]` ← 别人的操作都从这里来 |
| 在线成员 | `42["svr_user_status_change",[{id,nickname,avatar_url,...}]]` |
| 图片消息 | 正文多一个 `img: "data:image/jpeg;base64,..."`（长边 600px、≤52KB，整帧 ≤60KB） |
| 透明图片 | `img` 的 MIME 换成 `image/png` 或 `image/webp`（保留 alpha） |
| @ 消息 | 正文多一个 `mentions: [userId,...]` |
| 一次多图 | 仍是一图一帧，但每帧多带 `g`(组号) / `gi`(序号) / `gt`(总数)，接收端按 `g` 拼回同一气泡 |
| 建注释 | `["theatre","actors",<actorId>,"block_data_json","comments",<cid>,{"i":{id,parent_id,text,pinned,size,location,auto_layout,color_theme}}]` |
| 删除 | `["theatre","actors",<actorId>,"block_data_json","comments",<cid>,{"r":true}]` |

### 聊天正文（暗号）

普通注释和聊天注释靠前缀区分，没有暗号的帧原样放行，正常协作评论不受影响：

```
#%^&114514*/n{"v":1,"id":"...","c":"peer","u":931,"n":"小蓝","t":"文本","ts":1730000000000}
```

| 字段 | 含义 |
| --- | --- |
| `v` | 协议版本，目前 `1` |
| `id` | 消息 id（去重、合并图片分组用） |
| `c` | 类型：`self` / `peer` / `sys` |
| `u` | 发送者协作 id |
| `n` | 昵称 |
| `t` | 文本 |
| `img` | 可选，dataURL 图片 |
| `mentions` | 可选，被 @ 的协作 id 数组 |
| `g` / `gi` / `gt` | 可选，多图分组：组号 / 第几张 / 共几张 |
| `ts` | 时间戳（毫秒） |

### 踩过的坑

- **发和收是两个不同的事件名**：发 `operation`，收 `operation_relay`。只监听其中一个就会出现「发得出去、收不到」
- 注释挂在**演员**（`theatre.actors.<actorId>.block_data_json.comments`）下，不是场景下
- 角色 ID 不用等用户操作：`join_ack` 的 `doc.theatre` 里同时有 `scenes[当前场景].actors` 和 `theatre.actors`，两处任取其一（数组 / 字典两种写法都兼容）
- `revision` 必须严格 **+1** 递增，跳变会被服务器以 `code=10000000` 拒绝
- `parent_id` 可以是 `null`，注释坐标固定为 **`[100,100]`**
- **一条消息只发一条 op**，且发送前等编辑器安静 300ms、被拒自动换版本号重试一次——revision 是编辑器自己的递增计数，插队撞号会让编辑器弹「操作无法同步，已退出协作模式」
- 重写 `window.WebSocket` 后要把 `CONNECTING / OPEN / CLOSING / CLOSED` 常量挂回去，否则 `readyState !== WebSocket.OPEN` 恒成立，会误报「未连接」
- 进房时会扫一遍带暗号的历史注释（残留会随 `join_ack` 一起加载出来），发现就逐条删，最多 12 条、每 450ms 一条，普通注释一根手指都不碰

### 身份与作品名

| 数据 | 来源 |
| --- | --- |
| 协作 id | `operation_ack.user_id`（回执里带的就是自己） |
| 昵称 | `svr_user_status_change` 里对应 id 的 `nickname`（站点推的账号昵称） |
| 头像 | 同一条帧里的 `avatar_url`；没有就用昵称首字生成渐变圆 |
| 对方昵称 | 消息体里的 `u`（对方协作 id），收到后用在线成员表校正真名 |
| 作品名 | **实时读顶栏的作品名输入框**（`input[placeholder="作品名称不能为空"]`），不是 `join_ack` 的 `project_name`（那里是旧名 / 角色名） |

两边都不知道时不会瞎编：界面显示「协作成员」，标题旁胶囊的悬停提示里能看到 `协作 id`。

### 图片编码

发图前把图 `drawImage` 到 canvas，再扫一遍 alpha 通道：

| 情况 | 编码 | 说明 |
| --- | --- | --- |
| 不透明 | JPEG，0.82 起逐档降到 0.34 | 体积最省，`~9KB` / 600×450 很常见 |
| 透明 | 先无损 PNG；超 52KB 转 WebP（q 0.94 → 0.50） | 两者都保留 alpha |
| 还塞不进一帧 | 边长 ×0.84 逐级缩，600 → 200px | 细节多的透明大图会被缩 |

单图 ≤52KB（硬上限 54KB），整帧 ≤60KB。`inject.js` 侧正则本来就允许 `png|jpeg|webp`，老版本插件收到透明图也能显示。

## 界面与材质

材质跟着编辑器主题走：Kitten 把主色写在 `--theme-color-0`（`"255,120,41"` 这种，挂在 `body` 上，不在 `html`）。用 `MutationObserver` 盯着样式变化，一变就立刻读一次并派生出三档写进 `.cmc-root`（不再定时轮询）：

| 变量 | 值 | 用在哪 |
| --- | --- | --- |
| `--cmc-tint` | 原色 | 面板覆膜 |
| `--cmc-tint-soft` | 混白 62% | 自己的气泡、发送键、头像、悬浮球 |
| `--cmc-tint-deep` | 混黑 34% | 强调色 `--cmc-accent`：`@我` 标签、被 @ 气泡的圈、跳转胶囊文字 |

读不到 CSS 变量时兜底量顶栏背景色，换主题不用刷新。

| 层 | 做法 | 作用 |
| --- | --- | --- |
| 透 | 面板 `rgba(255,255,255,.26)` + `blur(44px)`；气泡 `blur(26px)` | 能看穿，背后的积木只是虚的 |
| 染 | 面板覆膜 `rgba(var(--cmc-tint), .08)`；自己的气泡 `rgba(var(--cmc-tint-soft), .52)`；发送键 `.64`；头像 `.58` | 一眼就是「这个编辑器的聊天框」，不是外来控件 |
| 厚 | 1px 发丝白描边 + 四边 `inset` 高光 + 底部内阴影 + 外侧大投影 | 玻璃有边、有厚度，白底上不会消失 |
| 分 | 自己偏主题色，对方是白玻璃；底部一角收成 6px 圆角 | 只靠一道色差 + 亮度差区分 |

**连接状态点固定绿色** `#27b56a`（在线语义，不随主题变），带一圈 16% 淡绿光晕；未读角标白底深字、被 @ 时绿底白字。整块界面没有黑色。

尺寸：悬浮球 44px（位置存 `localStorage.cmc.pos.v1`），面板 308×412 且 `maxHeight` 按球位置算，开合 220ms 弹簧。

几个坑：`backdrop-filter` 里的 `saturate()` 才是「有色调」的根源（删掉它比调透明度有用）；白玻璃悬浮球在白底上会「消失」，必须有描边 + 外投影；`--theme-color-0` 在 `body` 上，`documentElement` 读出来是空的。

## 排错

| 现象 | 处理 |
| --- | --- |
| 完全看不到悬浮球 | 没进协作房间（单人编辑不建连），或当前不是 `kitten4.codemao.cn/` |
| 报错 **Couldn't load icon icon16.png**（无法加载该扩展） | 装的那个目录里没有图标文件，通常只覆盖了 4 个 js/css。把 `icon16/32/48/128.png` 一起放到 `manifest.json` 旁边再刷新 |
| 图片发不出去 | 不透明图压 JPEG、透明图走 PNG/WebP，都控制在 ≈52KB 以内；仍失败说明压不小或一帧放不下，换张图 |
| 一直显示「正在同步房间信息…」 | 项目文档还没下发完，等一两秒；仍不行刷新页面 |
| 气泡显示「服务器拒绝了这条消息」 | 控制台看 `__cmChatDebug.lastAck.code`，`10000000` = revision 不连续 |
| 对方收不到但你这边有 ✓ | 对方没装 / 没刷新网页 / 版本不同 |
| 身份显示「协作成员」 | 在线成员帧还没到，稍等；控制台看 `__cmChatDebug.userId` 与 `selfName` |
| 想看完整状态 | 控制台执行 `__cmChatDebug` |

## 已知限制

1. 双方都得装，没装的人收不到。
2. 消息在服务器上确实是一条注释（坐标 100,100），1.5 秒后自删；这 1.5 秒内如果有人正好在看那个位置，理论上能瞄到一眼。
3. 极端情况（发完立刻关页面，或删除包撞版本号）作品里会残留一条注释，坐标 100,100 处能看到，手动删掉即可。
4. 只做文字和图片。透明图比不透明图占地儿，细节特别多的透明大图会被自动缩边长（最小 200px）才塞得进一帧。
5. 属于对官方协作协议的改造，编程猫改协议 / 加风控就可能失效——**随时可能坏，不保证长期可用**。

## 文件结构

```
manifest.json           扩展清单（MV3，world: MAIN，只匹配编辑器首页）
inject.js               注入脚本：接管 WebSocket、按真实协议收发注释、解析身份
content.js              聊天 UI（隔离世界）：界面、状态、回执、开合动画、未读
background.js           MV3 后台：装好/更新后给已打开的页面注入网页提示条
style.css               液态玻璃样式（cmc- 前缀，避免和编辑器冲突）
icon.svg                图标源文件（透明底）
icon16/32/48/128.png    扩展图标（根目录，清单直接引用）
assets/                 README 配图（由 tools/make-docs-shots.js 生成）
tests/                  协议回归测试 + UI 流程测试（不参与扩展运行）
tools/                  浏览器驱动、抓包脚本、图标生成、打包（不参与扩展运行）
dist/                   可分发版本
```
