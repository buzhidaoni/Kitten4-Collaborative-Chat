## 这是什么

编程猫 Kitten4 的多人协作只能改积木，没法说话。这个扩展在协作频道里开一条**旁路**：把聊天消息伪装成一条原生注释发出去，对方的插件在它变成积木评论之前截下来，所以编辑区上永远看不到东西。


> **免责声明**：仅供学习和交流使用，与编程猫官方无关。请勿用于刷屏、骚扰或其他影响他人正常协作的行为；因使用本扩展产生的一切后果由使用者自行承担。


## 文件结构

```
manifest.json           扩展清单（MV3，world: MAIN，只匹配编辑器首页）
inject.js               注入脚本：接管 WebSocket、按真实协议收发注释、解析身份
content.js              聊天 UI（隔离世界）：界面、状态、回执、开合动画、未读
style.css               液态玻璃样式（cmc- 前缀，避免和编辑器冲突）
icon.svg                图标源文件（透明底）
icon16/32/48/128.png    扩展图标（根目录，清单直接引用）
```

## 版本记录

- 3.6 **主题色立即跟随 + 透明图真透明**：主题跟随从 `setInterval(applyTheme, 2000)` 改成 `MutationObserver`（盯 `html` 的 `style/class` 属性与 `<head>` 里的样式表增删/文本），变化后 40ms 内应用（同一批变化会合并），配合点击、切标签、启动后几次快速补读；`applyTheme()` 有 `themeKey` 幂等判断，不会因为自己写 `cmc-root.style` 而循环。透明图去掉了缩略图 / 气泡图 / 大图底下那层淡棋盘格，也删掉了气泡的半透明白底和大图的 `#fff` 底，透明区域现在真的透出后面的玻璃。三个源码文件里的注释也全部清掉了。UI 测试 78/78。
- 3.5 **面板展开着也算未读**：面板开着、人切到别的标签或别的窗口（`document.hidden` 为真 / `window` 失焦）时收到的消息同样计入未读，标题照样显示 `（你有n条消息未读）…`，切回来立刻还原。实现：`attended()` 判「人还在不在这个标签」，`shouldCountUnread() = !open || !attended()`；监听 `visibilitychange` 与 `window focus/blur`，回来时若面板开着就清未读（`onBackToPage()`）；面板开着攒下的未读在收起面板时补到角标上。
- 3.4 **标签页标题显示未读**：面板关着收到消息，`document.title` 变成 `（你有n条消息未读）全新源码编辑器 - 搭积木一样有趣的编程工具`，打开面板（看过）立刻还原。不写死标题，而是每次从当前标题剥掉前缀现取站点标题；`MutationObserver` 盯 `<title>`，站点切作品 / 切场景改标题时把前缀补回去。
- 3.3 **支持透明图片**：发图前扫 canvas 的 alpha 通道，有透明像素就走 PNG（无损优先）/ WebP（超预算时，仍保留 alpha），不再把透明处压成黑块；不透明的图照旧压 JPEG。透明图塞不进一帧时自动缩边长（600 → 200px）。界面配合：预览条显示 `透明 N`，缩略图 / 气泡图 / 大图底下铺淡棋盘格。图标**保持平铺在根目录**（试过收进 `icon/`，Edge 拖 zip 安装时解包器会把子目录压平，实测解出 `icon?icon16.png` 这种乱码名，直接报 `Couldn't load icon`）；打包统一用 `tools/pack.py`，并检查图标不许带子目录。
- 3.2 **跟随编辑器主题色**：读 `--theme-color-0`（没有就量顶栏背景），派生 `--cmc-tint` / `-soft` / `-deep` 三档，面板覆膜、自己的气泡、发送键、头像、身份胶囊、系统提示、`@` 选中项、跳转胶囊都跟着染；换主题 2 秒内自动跟上（蓝 / 绿 / 紫都验证过）。
